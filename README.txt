Minal Vijay Patil Website (Static)

How to run locally:
1) Open index.html in a browser (double click), OR
2) Use a simple server:
   - python -m http.server 8080
   - then open http://localhost:8080

Google Form Embed:
- Open report.html and volunteer.html
- Replace PASTE_GOOGLE_FORM_EMBED_URL_HERE with your Google Form embed URL.

Replace content:
- Replace text inside HTML pages
- Replace placeholder images in assets/img
